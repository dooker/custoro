# MySQL 8.4 and MariaDB 11.4: what differs for Custoro

Things that bit, or that the repo already works around. Check a change against both with `scripts/schema-drift.sh`.

| Topic                                    | MySQL 8.4                                                                | MariaDB 11.4                                                                               | What to do                                                                                                                                                                                                           |
| ---------------------------------------- | ------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Collations                               | has `utf8mb4_0900_*`; server default `utf8mb4_0900_ai_ci`                | server default `utf8mb4_uca1400_ai_ci`; `0900` only in newer 11.4 patches (11.4.13 has it) | tables are `utf8mb4_unicode_ci`; never name a server-specific one. The hosted 11.4 lacked `0900` (PR 6), and the drift check on the newest image cannot catch a use: `grep -rn 0900 apps/api/migrations apps/api/db` |
| `ADD COLUMN/INDEX IF NOT EXISTS`         | syntax error                                                             | works                                                                                      | check `information_schema` first (`migrationHelpers.js`)                                                                                                                                                             |
| Recursive CTE limit                      | `cte_max_recursion_depth` (default 1000)                                 | `max_recursive_iterations` (default 1000)                                                  | set through a prepared statement chosen by `VERSION() LIKE '%MariaDB%'`                                                                                                                                              |
| `INSERT ... WITH RECURSIVE ... SELECT`   | works                                                                    | works                                                                                      | used in `gen-volume.sql`                                                                                                                                                                                             |
| `COALESCE(@unset_variable, 2000)`        | a number                                                                 | text, so `GREATEST()` compares `'50000'` > `'250000'`                                      | `CAST(... AS UNSIGNED)` user variables                                                                                                                                                                               |
| `MAX(CAST(x AS UNSIGNED)) + 1`           | DECIMAL, so `CAST(... AS CHAR)` gives `1.000000000000000000000000000000` | not checked                                                                                | cast to `UNSIGNED` once more before turning it into text                                                                                                                                                             |
| `COLUMN_DEFAULT` in `information_schema` | unquoted                                                                 | quoted strings                                                                             | compare within one server only (the drift script does)                                                                                                                                                               |
| Slow statements                          | `performance_schema` on                                                  | `performance_schema` OFF by default                                                        | MariaDB: `slow_query_log=1, long_query_time=0, log_output=TABLE`, read `mysql.slow_log`                                                                                                                              |
| Client in the image                      | `mysql`                                                                  | `mariadb`                                                                                  | `command -v mariadb \|\| command -v mysql`                                                                                                                                                                           |
| Root password variable (image)           | `MYSQL_ROOT_PASSWORD`                                                    | `MARIADB_ROOT_PASSWORD`                                                                    | pass both                                                                                                                                                                                                            |
| Client over TCP with `MYSQL_PWD`         | quiet                                                                    | prints a `--ssl-verify-server-cert` warning                                                | use the socket inside the container                                                                                                                                                                                  |

Also true on both:

- DDL is not transactional. A migration that fails halfway keeps its earlier statements, and `db-migrate` records only files that finished. Refuse bad data before the first `ALTER`.
- The API's pool has `multipleStatements` off, the migration connection has it on (`config/database.js`).
- `db-migrate` stores names as `/<file name>` in the `migrations` table.
- The generated column `invoices.number_sort` (`IF(number REGEXP '^[0-9]{1,18}$', CAST(number AS UNSIGNED), 0)`) is the same expression on both.
